# Approach
we create a set to determine the combined unique elements which X and Y can pass. if together they are able to pass all elements from 1 to n then the size of the set would be same as n. 
 
time complexity - `O(p+q)`
space complexity - `O(n)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
    int n=0; cin>>n;
    unordered_set<int> st;
    int p=0; cin>>p;
    while(p--){
        int num=0; cin>>num;
        st.insert(num);
    }
    int q=0; cin>>q;
    while(q--){
        int num=0; cin>>num;
        st.insert(num);
    }
    if(st.size() == n) cout << "I become the guy." << endl;
    else cout << "Oh, my keyboard!" << endl;
}
```
