# Approach
the total number of squares would be `m * n` and since each domino covers 2 squares, we divide `m * n` by 2. even if the product is odd, the integer division gives us the floor value. 

time complexity - `O(1)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int m = 0, n = 0;
    cin >> m >> n;

    cout << (m * n) / 2 << endl;

    return 0;
}
