# Approach

we traverse the array and keep track of the largest and second largest elements. we also keep the ind variable to keep track where we got the largest value i.e. bid and the second largest element which tells us about the second highest auction. 

time complexity - `O(n)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n = 0;
    cin >> n;

    vector<int> arr(n);

    for(int i = 0; i < n; i++){
        cin >> arr[i];
    }

    int largest = 0, seclar = 0;
    int ind = 0;

    for(int i = 0; i < n; i++){
        if(arr[i] > largest){
            seclar = largest;
            largest = arr[i];
            ind = i + 1;
        }
        else if(arr[i] > seclar){
            seclar = arr[i];
        }
    }

    cout << ind << endl;
    cout << seclar << endl;
}
```
