# Approach

Storing and traversing the grid simultaneously while maintaining a boolean variable `valid` to check for invalid squares.
Store the first element of each row and compare every other element in the same row with it. If there is a mismatch, `valid = false`.
Before moving to the next row, compare the first element of the current row with the first element of the previous row to ensure that adjacent rows do not have the same colour. If they match, `valid = false`.
If `valid` becomes false at any point, break out of the loops and print `NO`, otherwise print `YES`.

**Time Complexity:** `O(n * m)`

**Space Complexity:** `O(n * m)`

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n=0; int m=0;
    cin>>n; cin>>m;

    vector<vector<char>> arr(n, vector<char>(m));
    bool valid = true;

    for(int i=0;i<n;i++){
        cin>>arr[i][0];
        int first = arr[i][0];

        for(int j=1;j<m;j++){
            cin>>arr[i][j];

            if(arr[i][j] != first){ 
                valid = false; 
            }
        }

        if(!valid) break;

        if(i > 0 && first == arr[i-1][0]){
            valid = false; 
            break;
        }
    }

    if(valid) cout << "YES" <<endl;
    else cout << "NO" << endl;
}
```
