# Approach

In normal C++, we write code using statements, variables, input/output functions, and operators. However, in **Befunge**, we use symbols to perform operations, and there is no need for statements like `main()` or `cout`. We store and manipulate values using a stack ds.

- `&` takes the input value of `n` and pushes it onto the stack.
- `:` duplicates the top value of the stack, so we duplicate `n` twice to get three copies of it.
- `*` multiplies the top two values of the stack and pushes the result back. First, we calculate `n × n`, then push `2` and multiply again to get `2 × n × n`.
- `\` swaps the top two values of the stack, bringing `n` to the top.
- `-` subtracts `n` from `2 × n × n`, giving us `2 × n × n − n`.
- `.` prints the result.
- `@` terminates the program.

Thus, the Befunge code calculates the nth hexagonal number using the formula \(2n^2-n\).

# Code

```befunge
&::*2*\\-.@
```
