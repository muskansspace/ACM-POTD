# Approach

my initial approach was to use a set to check whether all the digits are distinct, but then i thought of a simpler way. 
i convert `num + 1` into a string and compare every pair of digits. if any two digits are equal, i increment `possible` and repeat the process until all digits are distinct.

time complexity - `O(k)`, where `k` is the number of numbers checked.
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int num = 0;
    cin >> num;

    string s = to_string(num + 1);
    int possible = num + 1;

    while(s[0] == s[1] || s[0] == s[2] || s[0] == s[3] ||
          s[1] == s[2] || s[1] == s[3] || s[2] == s[3]){
        possible += 1;
        s = to_string(possible);
    }

    cout << possible << endl;
}
