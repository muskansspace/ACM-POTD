# Approach

we traverse the array from left to right and if the current element is less than or equal to the previous one, we calculate the minimum number of increments required to make it greater by using multiples of `d`. we add these operations to `cnt` and update the current element accordingly.
finally, we print the total number of operations.

time complexity - `O(n)`
space complexity - `O(n)` auxiliary space (for the input vector)

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n=0; int d=0;
    cin>>n>>d;

    vector<int> arr(n);

    for(int i=0;i<n;i++){
        cin>>arr[i];
    }

    int cnt=0;

    for(int i=1;i<n;i++){
        if(arr[i]<=arr[i-1]){
            int need = ((arr[i-1]-arr[i])/d)+1;
            cnt += need;
            arr[i] += (need*d);
        }
    }

    cout << cnt << endl;
}
```
