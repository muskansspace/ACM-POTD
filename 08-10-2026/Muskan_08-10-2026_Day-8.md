# Approach

if the lengths of the two strings are not equal, `t` cannot be the correct translation of `s` and there is no point comparing. else, we compare the two strings in reverse order, i.e. the character at first index of `s` with the last index of `t` and so on. if at any point characters are not same, we give output as `NO` and stop.

time complexity - `O(n)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    string s; 
    string t; 
    cin>>s>>t;

    if(s.length() != t.length()) {
        cout << "NO" << endl;
        return 0;
    }

    int n = s.length();

    for(int i=0;i<n;i++){
        if(s[i] != t[n-1-i]){
            cout<<"NO"<<endl;
            return 0;
        }
    }

    cout<<"YES"<<endl;
}
