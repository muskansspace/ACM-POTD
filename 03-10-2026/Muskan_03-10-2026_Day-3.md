# Approach

if the size of the array is 1, then it is not possible to have another smallest distinct number, hence output `NO`.
sort the array and store the first number as the minimum number. Traverse the array to find the next smallest distinct number. If it does not exist, output `NO`.

**time Complexity:** `O(n log n) + O(n)` in the worst case, when all elements are equal to the smallest number.

**space Complexity:** `O(1)` auxiliary space.

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n=0; 
    cin>>n;
    if(n == 1){
        cout << "NO" << endl;
        return 0;
    }
    vector<int> arr(n);
    for(int i=0; i<n;i++){
        cin>>arr[i];
    }
    sort(arr.begin(), arr.end());
    int mini = arr[0]; 
    for(int i=0;i<n;i++){
        if(arr[i] != mini){
            cout << arr[i] << endl;
            return 0;
        }
    }

    cout << "NO" << endl;
}
