# Approach

traverse the string and count consecutive `#` characters. if the count reaches `k`, print `NO` and terminate; otherwise, reset the count whenever a `.` character is encountered. if no such sequence is found, print `YES`.

time complexity - `O(n)`
space complexity - `O(n)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n=0; int k=0; cin>>n>>k;
    string s;
    cin >> s;

    int i=0; int cnt=0;
    while(i < n){
        while(s[i] == '#'){
            cnt++;
            if(cnt >= k) { cout << "NO" << endl; return 0; }
            i++;
        }
        cnt=0;
        i++;
    }

    cout << "YES" << endl;
}
