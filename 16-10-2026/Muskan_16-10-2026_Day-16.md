# Approach

we consider a pair valid only when it satisfies both conditions. first, we find all possible pairs satisfying the first equation, where `a² + b = n`. for this, we run a loop while `a * a <= n` and calculate `b = n - a²`. then, we check whether these pairs satisfy the second equation, `a + b² = m`. if both conditions are satisfied, we increment the `ans` variable.

time complexity - `O(√n)`
space complexity - `O(√n)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n = 0, m = 0;
    cin >> n >> m;

    int a = 0;
    int ans = 0;
    vector<pair<int,int>> arr;

    while(a * a <= n){
        arr.push_back({a, n - (a * a)});
        a++;
    }

    for(int i = 0; i < arr.size(); i++){
        if(arr[i].first + (arr[i].second * arr[i].second) == m)
            ans++;
    }

    cout << ans;
}
