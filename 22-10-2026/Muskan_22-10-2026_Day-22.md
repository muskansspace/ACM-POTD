# Approach
we initialize the array of size `n²` with each charac marked as '.'
then we place a 'C' in every cell where the row and column indices have the same parity (both even or both odd). we increment `ans` for every 'C'. finally, we print the total number of 'C' and the resulting grid.

time complexity - `O(n²)`
space complexity - `O(n²)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n = 0;
    cin >> n;

    int ans = 0;
    vector<vector<char>> arr(n, vector<char>(n, '.'));

    for(int i = 0; i < n; i++){
        for(int j = 0; j < n; j++){
            if(i % 2 == 0 && j % 2 == 0){
                arr[i][j] = 'C';
                ans++;
            }
            else if(i % 2 != 0 && j % 2 != 0){
                arr[i][j] = 'C';
                ans++;
            }
        }
    }

    cout << ans << endl;

    for(int i = 0; i < n; i++){
        for(int j = 0; j < n; j++){
            cout << arr[i][j];
        }
        cout << endl;
    }
}
