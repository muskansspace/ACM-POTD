# Approach

we first sort the four lengths in ascending order. if the sum of any two consecutive smaller lengths is greater than the next length, they can form a triangle, so we print `"TRIANGLE"`.
** TRIANGLE INEQUALITY THEOREM **
otherwise, we check whether the sum of any two smaller lengths is equal to another length (degenerate triangle - collinear). if such a pair exists, we print `"SEGMENT"`. otherwise, we print `"IMPOSSIBLE"`.

time complexity - `O(1)` (sorting 4 elements would take 4 log 4 which is constant only)
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    vector<int> arr(4);

    for(int i=0;i<4;i++){
        cin>>arr[i];
    }

    sort(arr.begin(), arr.end());

    if(arr[0]+arr[1] > arr[2] || arr[1]+arr[2] > arr[3]){
        cout << "TRIANGLE" << '\n';
    }
    else if(arr[0]+arr[1]==arr[2] || arr[0]+arr[1]==arr[3] || arr[1]+arr[2]==arr[3]){
        cout << "SEGMENT" << '\n';
    }
    else cout << "IMPOSSIBLE" << '\n';
}
```
