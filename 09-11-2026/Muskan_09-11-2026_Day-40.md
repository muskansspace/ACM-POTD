# Approach

we find the smallest multiple of `k` that is strictly greater than `n`. if `n` is already divisible by `k`, we add `k` to get the next multiple. otherwise, we add the difference between `k` and the remainder (`n % k`) to reach the next multiple.

time complexity - `O(1)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n=0; int k=0;
    cin>>n>>k;

    if(n%k==0) cout << n+k << endl;
    else{
        cout << n+(k-(n%k)) << endl;
    }
}
```
