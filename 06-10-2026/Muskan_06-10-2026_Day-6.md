# Approach

we simply compare adjacent heights of the soldiers to determine the minimal difference in heights who could form the best reconnaissance. since the soldiers are standing in a circle, we also compare the first and the last soldier's heights in the array.

time complexity - `O(n)`

space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n=0; cin>>n;
    vector<int> arr(n);

    for(int i=0;i<n;i++){
        cin>>arr[i];
    }

    int first=-1;
    int second=-1;
    int mini=INT_MAX;

    for(int i=1;i<n;i++){
        if(abs(arr[i] - arr[i-1]) < mini){
            mini = abs(arr[i]-arr[i-1]);
            first=i;
            second=i+1;
        }
    }

    if(abs(arr[n-1] - arr[0]) < mini){
        first = 1; 
        second = n;
    }

    cout<< first <<  ' ' << second << endl;
}
