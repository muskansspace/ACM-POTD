# Approach

while both numbers are greater than `0`: if `a >= b`, add `a/b` to `cnt` and update `a` to `a%b`. otherwise, add `b/a` to `cnt` and update `b` to `b%a`. continue until either `a` or `b` becomes `0`.

time complexity - `O(log(max(a,b)))` 
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;

    while(n--) {
        long long a, b;
        cin >> a >> b;

        long long cnt = 0;

        while(a > 0 && b > 0) {
            if(a >= b) {
                cnt += a / b;
                a %= b;
            }
            else {
                cnt += b / a;
                b %= a;
            }
        }

        cout << cnt << endl;
    }

    return 0;
}
