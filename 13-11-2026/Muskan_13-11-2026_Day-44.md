# Approach

we check the position of the king on the chessboard. if it is at one of the four corners, it has `3` possible moves. if it is on an edge but not a corner, it has `5` possible moves. otherwise, it is somewhere in the middle of the board and has `8` possible moves.

time complexity - `O(1)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    string s;
    cin>>s;

    if(s == "a1" || s == "a8" || s == "h1" || s == "h8"){
        cout << 3 << endl;
    }
    else if(s[0] == 'a' || s[0] == 'h' || s[1] == '1' || s[1] == '8'){
        cout << 5 << endl;
    }
    else cout << 8 << endl;
}
```
