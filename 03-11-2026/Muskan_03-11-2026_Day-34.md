# Approach

we use sum to keep track of all the cubes. at every height i : 1,2,3....i cubes are required which is = cubes required for prev height (i-1) + i. 
we do this operation until the aggregate sum exceeds n.
time complexity - `O(√n)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n = 0;
    cin >> n;

    long long sum = 0;
    int cnt = 0;

    while(sum < n){
        cnt++;
        sum = (sum + cnt);
    }

    if(sum <= n) cout << cnt << endl;
    else cout << cnt-1 << endl;
}
```
