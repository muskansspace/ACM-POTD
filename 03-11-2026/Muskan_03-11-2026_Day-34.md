# Approach

we check if the total no. of cubes exceeds n. 
time complexity - `O(√n)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n = 0;
    cin >> n;

    long long sum = 0;
    int cnt = 0;

    while(true){
        cnt++;
        long long cubes = 1LL * cnt * (cnt + 1) / 2;

        if(sum + cubes > n) {
            cnt--;
            break;
        }

        sum += cubes;
    }

    cout << cnt << endl;
    return 0;
}
```
