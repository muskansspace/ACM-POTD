# Approach

we compare both strings character by character after converting each character to lowercase. if the character in `s1` is smaller, we output `-1`; if it is greater, we output `1`. if all characters are equal, we output `0`.

time complexity - `O(n)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    string s1, s2;
    cin >> s1 >> s2;

    for(int i = 0; i < s1.length(); i++){
        if(tolower(s1[i]) < tolower(s2[i])){
            cout << -1 << endl;
            return 0;
        }
        else if(tolower(s1[i]) > tolower(s2[i])){
            cout << 1 << endl;
            return 0;
        }
    }

    cout << 0 << endl;
}
