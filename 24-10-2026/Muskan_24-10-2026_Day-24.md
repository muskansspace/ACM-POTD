# Approach

we first check if the password has at least 5 characters. if not, there is no need to check for the rest of the cases and we print `Too weak`. otherwise, we have 4 variables, each for a specific validity check. we traverse the string and if all three conditions are satisfied, we print `Correct`; otherwise, we print `Too weak`.

time complexity - `O(n)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    string s;
    cin >> s;

    bool small = false;
    bool large = false;
    bool digit = false;
    bool len = false;

    if(s.length() < 5) cout << "Too weak" << endl;
    else{
        len = true;

        for(int i = 0; i < s.length(); i++){
            if(s[i] >= 'a' && s[i] <= 'z') small = true;
            else if(s[i] >= 'A' && s[i] <= 'Z') large = true;
            else if(s[i] >= '0' && s[i] <= '9') digit = true;
        }

        if(small && large && digit && len) cout << "Correct" << endl;
        else cout << "Too weak" << endl;
    }
}
```
