# Approach

if `n` is even, we can divide it into two equal parts. if `n/2` is even, both parts are already composite, so we output `n/2` and `n/2`. otherwise, we adjust the two parts by adding `1` to the first and subtracting `1` from the second, making both even and composite.
if `n` is odd, we use `9` as the first number because it is the smallest odd composite number and would work the lowest possible testcase i.e. 13. since `n` is odd, `n - 9` is even, and for the given constraints it is composite as well.

time complexity - `O(1)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n = 0;
    cin >> n;

    if(n % 2 == 0){
        if((n/2) % 2 == 0)
            cout << n/2 << ' ' << n/2 << endl;
        else
            cout << n/2 + 1 << ' ' << n/2 - 1 << endl;
    }
    else{
        cout << 9 << ' ' << n-9 << endl;
    }
}
```
