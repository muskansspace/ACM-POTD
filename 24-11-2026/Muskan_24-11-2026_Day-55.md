# Approach

first, we sort the array of square side lengths in ascending order. since all squares start at `(0,0)` and are nested, choosing the point `(a,a)` means it belongs to all squares whose side length is greater than or equal to `a`.
to find a point belonging to exactly `k` squares, we select `arr[n-k]` after sorting. This value ensures that exactly `k` squares have side lengths greater than or equal to it. we print `(arr[n-k], arr[n-k])` as our answer. If `k > n` that would mean that the point should belong to more than the number of squares available, hence we print `-1`.

time complexity : `O(n log n)` — sorting the array.
space complexity : `O(n)` — storing the array.

# Code
\`\`\`cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
    int n=0; int k=0; cin>>n>>k;
    vector<int> arr(n);
    for(int i=0;i<n;i++){
        cin>>arr[i];
    }
    sort(arr.begin(), arr.end());
    if(k > n) cout << -1 << endl;
    else{
        int ind = n-k;
        cout << arr[ind] << ' ' << arr[ind] << endl;
    }
}
