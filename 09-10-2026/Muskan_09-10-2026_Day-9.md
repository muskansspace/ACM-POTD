# Approach
in the triangular number concept, for every new row, `row` dots are added to keep it equilateral (all sides equal), and the total number of dots `1+2+3+4+...+n` forms a valid triangular number.
to check if the given number is a triangular number or not, i don't know the row number, so i calculate the sum by adding the dots in each row till the total sum is greater than or equal to the given number. if the sum equals the number, it is a valid triangular number; otherwise, it is not.

time complexity - `O(√n)` ** (the time complexity is **`O(√n)`**, not `O(n)`, because the sum of the first `k` natural numbers is \(k(k+1)/2\), so the loop runs roughly \(\sqrt{n}\) times.)
space complexity - `O(1)`

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n=0; cin>>n;
    int i=1; int sum=1;

    while(sum < n){
        i+=1;
        sum+=i;
    }

    sum==n ? cout<<"YES"<<endl : cout<<"NO"<<endl;
}
