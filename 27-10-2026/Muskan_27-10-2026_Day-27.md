# Approach

we store the `n-1` numbers in an array and sort the array. then, we traverse the array and compare each element with its expected value, `i+1`. if they don't match, we output the missing number. if all elements match, the missing number is `n`.

time complexity - `O(n log n)`
space complexity - `O(n)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n = 0;
    cin >> n;

    vector<int> arr(n-1);

    for(int i = 0; i < n-1; i++){
        cin >> arr[i];
    }

    sort(arr.begin(), arr.end());

    for(int i = 0; i < n-1; i++){
        if(arr[i] != i+1){
            cout << i+1 << endl;
            return 0;
        }
    }

    cout << n << endl;
    return 0;
}
```
