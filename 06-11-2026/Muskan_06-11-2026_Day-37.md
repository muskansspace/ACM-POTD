# Approach

we calculate the maximum number of pairs using `min(red, blue)` because each pair requires one red and one blue sock. for the remaining socks, we need to find possible number of pairs so we divide by 2.

time complexity - `O(1)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int red = 0, blue = 0;
    cin >> red >> blue;

    cout << min(red, blue) << ' ' << (max(red, blue) - min(red, blue))/2 << endl;
}
```
