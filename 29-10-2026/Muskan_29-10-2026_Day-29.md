# Approach

we find the middle using `n/2`. for each row, we print `*` characters on both sides and `D` characters in the middle. the number of stars is determined by the absolute difference between the current row and the middle row, while the number of `D`s is `n - 2 * stars`.

time complexity - `O(n²)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n = 0;
    cin >> n;

    int mid = n/2;

    for(int i = 0; i < n; i++){
        for(int j = 0; j < abs(i-mid); j++){
            cout << '*';
        }

        for(int j = 0; j < n-(2*abs(i-mid)); j++){
            cout << 'D';
        }

        for(int j = 0; j < abs(i-mid); j++){
            cout << '*';
        }

        cout << endl;
    }
}
```
