# Approach

we store the score of the k-th participant and count how many participants have a positive score greater than or equal to it. since the scores are sorted in non-increasing order, we stop counting when a score < k.

time complexity - `O(n)`
space complexity - `O(n)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n = 0, k = 0;
    cin >> n >> k;

    vector<int> arr(n);

    for(int i = 0; i < n; i++){
        cin >> arr[i];
    }

    int score = arr[k-1];
    int cnt = 0;

    for(int i = 0; i < n; i++){
        if(arr[i] > 0 && arr[i] >= score) cnt++;
        else break;
    }

    cout << cnt << endl;
}
