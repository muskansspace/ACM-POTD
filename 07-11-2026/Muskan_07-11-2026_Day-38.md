# Approach

we use an unordered set to store all the unique bulbs that can be turned on by the given buttons. for each button, we read the number of bulbs it controls and insert their bulb numbers into the set. finally, if the set size is equal to `m`, it means all bulbs can be turned on, so we print `YES`; otherwise, we print `NO`.

time complexity `O(no. of bulbs switched on by buttons)` on average
space complexity - `O(m)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n=0; int m=0;
    cin>>n>>m;

    unordered_set<int> st;

    while(n--){
        int q=0; cin>>q;

        while(q--){
            int num=0; cin>>num;
            st.insert(num);
        }
    }

    if(st.size() == m) cout << "YES" << endl;
    else cout << "NO" << endl;
}
```
