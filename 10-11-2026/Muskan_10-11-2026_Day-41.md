# Approach

we store each element along with its original 1-based index in a vector of pairs. then, we sort the pairs based on their values. using two pointers, we print the original indices of the smallest and largest elements together. we continue until the two pointers meet.

time complexity - `O(n log n)` due to sorting
space complexity - `O(n)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n=0;
    cin>>n;

    vector<int> arr(n);
    vector<pair<int,int>> pairs;

    for(int i=0; i<n; i++){
        cin>>arr[i];
        pairs.push_back({arr[i], i+1});
    }

    sort(pairs.begin(), pairs.end());

    int i=0; int j=n-1;

    while(i<j){
        cout << pairs[i].second << ' ' << pairs[j].second << endl;
        i++; j--;
    }
}
```
