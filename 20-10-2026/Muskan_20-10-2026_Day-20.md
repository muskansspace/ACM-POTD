# Approach
change the first letter of the input string to uppercase and print the updated string.

time complexity - `O(1)`
space complexity - `O(1)` auxiliary space

# Code
```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    string s;
    cin >> s;

    s[0] = (char)toupper(s[0]);

    cout << s << endl;

    return 0;
}
