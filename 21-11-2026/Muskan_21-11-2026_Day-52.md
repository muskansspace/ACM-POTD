# Approach

we count the occurrences of `1`, `2`, and `3` in the array using three separate counters. `n - cnt1`, `n - cnt2`, and `n - cnt3` represent the number of elements that are not equal to `1`, `2`, and `3`, respectively. we take the minimum of these three values to get the minimum number of elements that need to be removed so that all remaining elements are equal.

time complexity - `O(n)`
space complexity - `O(n)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n=0; cin>>n;
    vector<int> arr(n);

    int cnt1=0; int cnt2=0; int cnt3=0;

    for(int i=0;i<n;i++){
        cin>>arr[i];

        if(arr[i] == 1) cnt1++;
        else if(arr[i] == 2) cnt2++;
        else cnt3++;
    }

    cout << min(n-cnt1, min(n-cnt2, n-cnt3)) << endl;
}
