# Approach

we store the four numbers in an unordered set that would only keep unique elements, hence to determine how many more horseshoes we'll need to have 4 unique we subtract the size of the set from 4.

time complexity - `O(1)` on average
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    unordered_set<int> st;

    for (int i = 0; i < 4; i++) {
        int num;
        cin >> num;
        st.insert(num);
    }

    cout << 4 - st.size() << endl;
}
