# Approach

we first take the input of the maximum number of matchboxes we can carry (`n`), the number of available boxes (`m`), and the number of matches and price per match for each box.
we sort the vector of pairs in descending order based on the price per match using a custom comparator.
then, if the current box has fewer matchboxes than or equal to our remaining capacity, we take all its matches and add their total value to `ans`. we update `n` by subtracting the number of matchboxes taken.
if the current box has more matchboxes than our remaining capacity, we take only the remaining n(left) matchboxes, add their value to `ans`, and stop.

time complexity - `O(m log m)` due to sorting
space complexity - `O(m)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;
static bool comp(pair<int,int> a, pair<int,int> b){
    return a.second > b.second;
}

int main(){
    int n=0; int m=0;
    cin>>n>>m;
    vector<pair<int,int>> arr(m);
    for(int i=0;i<m;i++){
        cin>>arr[i].first>>arr[i].second;
    }
    sort(arr.begin(), arr.end(), comp);

    int ans=0;
    for(int i=0;i<m;i++){
        if(arr[i].first <= n){
            ans += arr[i].first * arr[i].second;
            n -= arr[i].first;
        }
        else{
            ans += n * arr[i].second;
            break;
        }
    }
    cout << ans << endl;
}
```
