
# Approach
we use an `unordered_set` to store unique strings. read each string using `getline()` and insert it into the set. since a set stores only unique elements, duplicate strings are automatically ignored. then we print the size of the set to get the count of distinct strings.
*imp - we used cin.ignore() to remove the '\n' newline character after we take input of n to avoid an empty charac to go in the set.
time complexity - `O(n)` average
space complexity - `O(n)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n=0; cin>>n;
    cin.ignore();

    unordered_set<string> st;

    for(int i=0;i<n;i++){
        string s;
        getline(cin, s);
        st.insert(s);
    }

    cout << st.size() << endl;
}
```
