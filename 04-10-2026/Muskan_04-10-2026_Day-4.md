# Approach

first sort the array as otherwise we would have to traverse the entire array again and again for each element to check for difference resulting in `O(n^2)` time complexity which would be expensive.
then i used the sliding window approach. we increment the right until the difference between the left and right elements is not greater than `d`. if it is, we increment the left pointer until the gap is again less. if the gap is less we increment the `cnt += (right - left)` to include all the valid cases.

for eg : `{1,2,3}` and `d = 2`, initially `cnt` would become `1` when the left pointer is at index `0` and right pointer is at index `1`. then when right pointer is at index `2`, if we only increment `cnt` by `1`, we would miss a valid case of `{2,3}` as we increment left only when the gap becomes more than `d`. at index `2`, valid cases would be `{1,3}` and `{2,3}`, hence `cnt += right-left`.

finally, we give output as `2*cnt` as both `{1,2}` and `{2,1}` are considered as different.

time complexity - `O(n log n)` for sorting + `O(n)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n=0; cin>>n;
    int d=0; cin>>d;

    vector<int>arr(n);

    for(int i=0;i<n;i++){
        cin>>arr[i];
    }

    sort(arr.begin(), arr.end());

    int cnt=0;
    int left=0; int right=1;

    for(right; right<n;right++){
        while(arr[right]-arr[left] > d){
            left++;
        }
        cnt += (right-left);
    }

    cout << 2*cnt << endl;
}
