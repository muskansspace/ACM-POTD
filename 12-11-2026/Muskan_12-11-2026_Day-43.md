# Approach

the phrase starts with `I` and ends with `it`. if `i` is odd, we print `hate that I` otherwise `love that I` according to the pattern.

time complexity - `O(n)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n=0;
    cin>>n;

    int i=1;
    cout << "I ";

    while(i < n){
        if(i%2!=0) cout << "hate that I ";
        else cout << "love that I ";

        i++;
    }

    if(i%2!=0) cout << "hate it" << endl;
    else cout << "love it" << endl;
}
```
