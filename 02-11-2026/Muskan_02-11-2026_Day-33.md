# Approach

if `n` is even, we simply output `n/2` as for every 2 consecutive numbers there's an aggregate increment of 1. if `n` is odd, we calculate `(n-1)/2` and subtract `n` (the last odd number) from it.

time complexity - `O(1)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    long long n = 0;
    cin >> n;

    if(n % 2 == 0){
        cout << n/2 << endl;
    }
    else{
        long long ans = 0;
        ans += (n-1)/2;
        ans -= n;
        cout << ans << endl;
    }
}
```
