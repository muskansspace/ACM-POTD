# Approach
we count the number of lowercase and uppercase letters. if `low >= up`, we convert every character in the string to lowercase; otherwise, we convert every character to uppercase.

time complexity - `O(n)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    string s;
    cin >> s;

    int low = 0, up = 0;

    for(int i = 0; i < s.length(); i++){
        if(s[i] >= 'a' && s[i] <= 'z') low++;
        else up++;
    }

    if(low >= up){
        for(int i = 0; i < s.length(); i++){
            s[i] = tolower(s[i]);
        }
    }
    else{
        for(int i = 0; i < s.length(); i++){
            s[i] = toupper(s[i]);
        }
    }

    cout << s << endl;
}
