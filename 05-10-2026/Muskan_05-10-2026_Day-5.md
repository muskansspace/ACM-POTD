# Approach

if the borze charac is `.` there is no doubt and the digit would be `0` but if the charac is `-` then we need to check the next charac. if the next charac is `.` then the digit would be `1` else `2`. if the charac is `-` we are required to check the next charac too hence we increment `i` by 2 so we don't check the charac at same index again.
time complexity - `O(n)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    string s; cin>>s;
    int n = s.length();
    int i=0;
    string ans;

    while(i < n){
        if(s[i] == '.') { 
            ans+='0'; 
            i++; 
        }
        else if(s[i] == '-' && s[i+1] == '.') { 
            ans+='1'; 
            i+=2; 
        }
        else { 
            ans+='2'; 
            i+=2; 
        }
    }

    cout << ans << endl;
}
