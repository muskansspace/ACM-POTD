# Approach

we calculate the sum of all elements and find the largest element i.e. the mug with max volume. since sereja has n-1 friends we can exclude one mug and its optimal to leave out the mug with max volume. if the remaining mugs total volume is greater than `s` i.e. the capacity of the cup, we output `NO`; otherwise, we output `YES`.

time complexity - `O(n)`
space complexity - `O(n)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n = 0, s = 0;
    cin >> n >> s;

    vector<int> arr(n);
    int largest = 0, sum = 0;

    for(int i = 0; i < n; i++){
        cin >> arr[i];
        largest = max(arr[i], largest);
        sum += arr[i];
    }

    sum -= largest;

    if(sum > s) cout << "NO" << endl;
    else cout << "YES" << endl;

    return 0;
}
```
