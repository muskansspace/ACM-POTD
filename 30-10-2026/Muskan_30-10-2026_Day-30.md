# Approach

we use an `ans` variable to track the number of rooms that have space for 2 or more than two people. for every room, if the difference in `p` and `q` is greater than or equal to `2`, we increment `ans`.

time complexity - `O(n)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n = 0;
    cin >> n;

    int ans = 0;

    for(int i = 0; i < n; i++){
        int p = 0, q = 0;
        cin >> p >> q;

        if((q - p) >= 2) ans++;
    }

    cout << ans << endl;
}
```
