# Approach

we first check if the string length is less than `26`. if it is, we output `NO` because it cannot contain all 26 letters. otherwise, we create a vector of size `26` to keep track of the frequency of each alphabet. we convert every character to lowercase and update its corresponding index in the vector. finally, if any alphabet has a frequency of `0`, we output `NO`; otherwise, we output `YES`.

time complexity - `O(n)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n = 0;
    cin >> n;

    string s;
    cin >> s;

    if(n < 26) cout << "NO" << endl;
    else{
        vector<int> arr(26, 0);

        for(int i = 0; i < n; i++){
            arr[tolower(s[i]) - 'a']++;
        }

        for(int i = 0; i < 26; i++){
            if(arr[i] == 0){
                cout << "NO" << endl;
                return 0;
            }
        }

        cout << "YES" << endl;
    }
}
```
