# Approach

we count the occurrences of `1`, `2`, and `3` in the string. then, we traverse the string at every second index and place all the `1`s first, then `2`s and then the `3`s.

time complexity - `O(n)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
    string s;
    cin >> s;

    int cnt1 = 0, cnt2 = 0, cnt3 = 0;

    for(int i = 0; i < s.length(); i++){
        if(s[i] == '1') cnt1++;
        else if(s[i] == '2') cnt2++;
        else if(s[i] == '3') cnt3++;
    }

    for(int i = 0; i < s.length(); i += 2){
        if(cnt1 > 0){
            s[i] = '1';
            cnt1--;
        }
        else if(cnt2 > 0){
            s[i] = '2';
            cnt2--;
        }
        else if(cnt3 > 0){
            s[i] = '3';
            cnt3--;
        }
    }

    cout << s << endl;
    return 0;
}
