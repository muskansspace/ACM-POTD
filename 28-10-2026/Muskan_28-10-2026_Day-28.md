# Approach

we use an unordered set to store the distinct characters in the string. starting from index `1`, we traverse the string by incrementing the index by `3` each time and insert the characters into the set. since a set stores only unique characters, its size gives us the number of distinct letters. if the string length is at most `2`, we output `0`.

time complexity - `O(n)` on average
space complexity - `O(n)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    string s;
    getline(cin, s);

    unordered_set<char> st;
    int i = 1;

    while(i < s.length()){
        st.insert(s[i]);
        i += 3;
    }

    if(s.length() <= 2) cout << 0 << endl;
    else cout << st.size() << endl;
}
```
