# Approach

take the string as input and initialize `curr` with the first character and `cnt` with `1`. traverse the string starting from index `1`. if the current character is equal to `curr`, increment `cnt`. otherwise, update `curr` to the current character and reset `cnt` to `1`.
if `cnt` becomes greater than or equal to `7`, print `YES` and terminate. else if the loop completes without finding seven consecutive identical characters, print `NO`.

time complexity - `O(n)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    string s; cin>>s;
    char curr = s[0]; int cnt = 1;

    for(int i=1;i<s.length();i++){
        if(s[i] == curr) cnt++;
        else {
            curr = s[i]; cnt = 1;
        }

        if(cnt >= 7) { 
            cout << "YES" << endl; 
            return 0; 
        }
    }

    cout << "NO" << endl;
}
