# Approach

to read the input string, i used `getline(cin, s)` instead of `cin` only, as `cin` stops reading the input once it encounters a whitespace. then we start reading from the end to get the first alphabet character and convert it to lowercase (so we don't have to check separately for lowercase and uppercase). lastly, if the character is a vowel, we output `YES`, else `NO`.

time complexity - `O(n)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    string s;
    getline(cin, s);

    int i=s.length()-1;
    char c;

    while(i>=0){
        if(isalpha(s[i])){
            c = tolower(s[i]);
            break;
        }
        i--;
    }

    if(c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u' || c == 'y'){
        cout << "YES" << endl;
    }
    else cout << "NO" << endl;
}
