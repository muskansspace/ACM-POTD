# Approach
if we are on rank a that means we have already reached all the previous ranks till a-1. to reach rank b we need to cover all between a and b-1. since i have used 0 based indexing, a person who has reached rank a stands on `i == a-1` and to reach till rank b (`i == b-1`) we sum up all till `i == b-2`.

time complexity - `O(n)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n=0; cin>>n;
    vector<int> arr(n-1);

    for(int i=0;i<n-1;i++){
        cin>>arr[i];
    }

    int a=0; int b=0; 
    cin>> a >> b;

    int ans=0;

    for(int i=0; i < n-1;i++){
        if(i >= a-1 && i < b-1){
            ans+=arr[i];
        }

        if(i >= b)break;
    }

    cout << ans << endl;
}
