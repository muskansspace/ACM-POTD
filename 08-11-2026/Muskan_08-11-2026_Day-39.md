
# Approach

for every `n` >= 2, the last two digits of `5^n` are always `25`. hence, we directly print `25` without calculating the power.

time complexity - `O(1)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n=0;
    cin>>n;
    cout << 25 << endl;
}
```
