# Approach

we maintain a counter `cnt` to track the length of the current strictly increasing contiguous segment. if the current element is greater than the previous element, we increment `cnt`; otherwise, we reset it to `1`. we also maintain `maxi` to store the maximum length found so far.

time complexity - `O(n)`
space complexity - `O(n)` auxiliary space (for the input vector)

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n=0;
    cin>>n;

    vector<int> arr(n);

    for(int i=0; i<n; i++){
        cin>>arr[i];
    }

    int cnt=1; int maxi=1;

    for(int i=1; i<n; i++){
        if(arr[i] > arr[i-1]) cnt++;
        else cnt=1;

        maxi=max(maxi, cnt);
    }

    cout << maxi << endl;
}
```
