# Approach

if `n` is even, the first half of the sequence contains odd numbers and the second half contains even numbers. if `k` lies in the first half, print the `k`th odd number using `2*k-1`; otherwise, adjust `k` by subtracting the number of odd elements and print the corresponding even number. for odd `n`, the first half contains one extra odd number, so the boundary is `n/2+1`, and the same logic is applied with the adjusted index.

time complexity - `O(1)`

space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    long long n=0; long long k=0; cin>>n>>k;

    if(n % 2 == 0){
        if(k <= n/2) cout << 2*k - 1 << endl;
        else{
            k = k-(n/2);
            cout << 2*k << endl;
        }
    }
    else{
        if(k <= (n/2)+1) cout << 2*k - 1 << endl;
        else{
            k = k- n/2 - 1;
            cout << 2*k << endl;
        }
    }
}
