# Approach

we create an array of size `n+1` initialized with `0`. we mark for Arthur first `1` in the hash array. then, we mark those who are not already marked as `2` for Alexander. finally, we print the array. 

time complexity - `O(n)`
space complexity - `O(n)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n = 0, a = 0, b = 0;
    cin >> n >> a >> b;

    vector<int> hashh(n+1, 0);

    for(int i = 0; i < a; i++){
        int num = 0;
        cin >> num;
        hashh[num] = 1;
    }

    for(int i = 0; i < b; i++){
        int num = 0;
        cin >> num;
        if(hashh[num] == 0) hashh[num] = 2;
    }

    for(int i = 1; i < n+1; i++){
        cout << hashh[i] << ' ';
    }

    return 0;
}
```
