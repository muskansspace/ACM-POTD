# Approach

- take a `3x3` grid as input to store the number of times each cell is pressed.
- initialize another `3x3` grid `ans` with all values set to `1`, representing the initially lit lights.
- traverse the input grid and check if the number of presses for each cell is odd.
- if it is odd, toggle the corresponding light and its adjacent lights (up, down, left, right). toggling means changing `1` to `0` or `0` to `1`.
- check boundary conditions before toggling adjacent cells to avoid accessing indices outside the grid.
- finally, print the resulting `3x3` grid.

time complexity - `O(1)` since the grid size is fixed at `3x3`.
space complexity - `O(1)` auxiliary space since both grids have fixed dimensions.

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    vector<vector<int>> grid(3, vector<int>(3));
    for(int i=0;i<3;i++){
        for(int j=0;j<3;j++){
            cin>>grid[i][j];
        }
    }

    vector<vector<int>> ans(3, vector<int>(3,1));

    for(int i=0;i<3;i++){
        for(int j=0;j<3;j++){
            if(grid[i][j] % 2 != 0){
                ans[i][j] == 0 ? ans[i][j] = 1 : ans[i][j] = 0;

                if(i-1 >= 0) 
                    ans[i-1][j] == 0 ? ans[i-1][j] = 1 : ans[i-1][j] = 0;

                if(i+1 < 3) 
                    ans[i+1][j] == 0 ? ans[i+1][j] = 1 : ans[i+1][j] = 0;

                if(j-1 >= 0) 
                    ans[i][j-1] == 0 ? ans[i][j-1] = 1 : ans[i][j-1] = 0;

                if(j+1 < 3) 
                    ans[i][j+1] == 0 ? ans[i][j+1] = 1 : ans[i][j+1] = 0;
            }
        }
    }

    for(int i=0;i<3;i++){
        for(int j=0;j<3;j++){
            cout << ans[i][j];
        }
        cout << '\n';
    }
}
