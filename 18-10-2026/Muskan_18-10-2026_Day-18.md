# Approach

we store the first character in `prev_i` and traverse the string from the second character. if the current character is equal to the previous character, we increment `cnt` because one character needs to be removed. otherwise, we update `prev_i` to the current character. finally, we output the total count of characters to remove.

time complexity - `O(n)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n = 0;
    cin >> n;

    string s;
    cin >> s;

    char prev_i = s[0];
    int cnt = 0;

    for(int i = 1; i < n; i++){
        if(s[i] == prev_i){
            cnt++;
        }
        else{
            prev_i = s[i];
        }
    }

    cout << cnt << endl;
}
