# Approach

we calculate the total cost of `w` bananas using the AP formula, where the cost of each banana increases by `k`. then, we compare the total cost with the amount `n` he already has. if the cost is greater than `n`, we output the difference; otherwise, we output `0`.

time complexity - `O(1)`
space complexity - `O(1)` auxiliary space

# Code

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int k = 0, n = 0, w = 0;
    cin >> k >> n >> w;

    long long cost = 1LL * k * w * (w+1) / 2;

    if(cost >= n) cout << cost - n << endl;
    else cout << 0 << endl;
}
```
